Sharding vertical

Los usuarios viven en una base aparte y sus columnas se separan: los datos básicos en usuarios y el perfil en usuarios_perfil.

Las dos tablas del usuario

Los datos básicos se consultan todo el tiempo; el perfil solo cuando se necesita.

usuarios datos básicos
  1. id · entero
  2. nombre · texto
  3. email · texto
  4. creado_en · fecha
usuarios_perfil perfil
  1. usuario_id · enlace
  2. biografia · texto largo
  3. foto · imagen
  4. preferencias · JSON
Ambas en db_usuarios · se unen por usuario_id solo al pedir el perfil completo.
